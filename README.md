# AI Traffic Congestion Predictor

An AI-based machine learning application that predicts traffic congestion levels based on traffic-related input data.

## Features
- Predicts traffic congestion level
- Classifies traffic as Low, Medium, High, or Critical
- Machine Learning based prediction
- Simple Streamlit web interface
- Data analysis using Pandas

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Machine Learning

## Traffic Levels
- Low Traffic
- Medium Traffic
- High Traffic
- Critical Traffic

## How to Run

Install the required libraries:

pip install pandas scikit-learn streamlit

Run the application:

streamlit run app.py

## Project Files
- `app.py` – Streamlit application
- `traffic_data.csv` – Traffic dataset

## Future Scope
The project can be enhanced with real-time traffic data, GPS/location information, weather conditions, and live traffic APIs.
